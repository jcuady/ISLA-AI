Why running the AI locally

A cloud model cannot check a secret without being told it.

Asking an external model &#ldquo;is this sensitive personal information?&#rdquo; is itself a disclosure to a third party in a foreign jurisdiction — the act is the breach it exists to prevent. The question only has an answer on hardware the data already lives on.

The disclosure problem

Redaction is the one AI task that cannot be outsourced, because performing it requires handing over the exact data it exists to protect. Isla AI runs 18 Philippine entity detectors — Luhn-validated card and account numbers, SSS, TIN, GCash — on the machine in front of you, then re-runs the whole detector over its own output before anything moves.

Air-gapped banks are the norm

Core-banking estates and ISO 27001-sealed networks exist precisely because the breach window is measured in hours. Isla AI is demonstrated with the cable pulled: the status chip is a live socket probe, so pulling the network mid-demo changes the answer in front of you. A control that degrades when the WAN blinks was never a control.

Economics that survive scale

Every paste a compliance officer scans is a per-call invoice at a cloud vendor — for a task that takes 0.2 ms on a CPU already in the building. There is no marginal cost per scan, and no vendor sitting between the bank and its own regulator’s questions.

Regulators already asked

NPC Advisory 2024-04 applies the Data Privacy Act to AI systems processing personal data. The evidence is now producible locally, as a SHA-256 hash chain that stores entity counts, verdicts and latency — and never the customer text. Answering “what did you collect on the fifteenth?” does not itself become a breach.

Confidentiality you can audit

“Read our DPA” is a contractual promise. “No module outside the air-gap probe holds a network primitive, the browser is forbidden from fetching off-origin by a default-src 'none' policy, and both are asserted on every CI push” is a test. A CI job runs the PII engine with zero pip installs to prove the hot path is standard library only.

The honest counterweight

Local does not automatically mean better. A 3B model is a 3B model. Isla AI’s correctness comes from retrieval, not scale: answers are quoted verbatim from cited spans, so the worst case is an irrelevant chunk rather than an invented section number. Measured both ways, and the trade is documented rather than implied.

What ships

Three controls, one process, one machine.

Each one is a distinct control a bank has to evidence separately, and each one produces its own proof in the ledger.

Egress Guard

Paste anything a staff member might send to an external AI. Eighteen Philippine entity types are detected, redacted, then re-detected by a verification pass. Anything that survives verification escalates instead of shipping.

DPA Copilot

Ask the Data Privacy Act in Taglish or English. Hybrid retrieval over seven real instruments returns quoted spans with resolvable citations — and refuses outright when the evidence is too thin, because a wrong circular number is worse than no answer.

citation accuracy 100% · correct refusal 100%

Audit Ledger

Every action writes a SHA-256 hash-chained record. Each entry links to the last, so altering one invalidates everything after it and a single pass detects it. Counts and verdicts only — the customer text is never written to disk.

verified in one pass · contains no raw PII

Problem & Usefulness

A named, narrow, real obligation: a Philippine bank’s data-privacy officer has NPC advisories, circulars and BSP memos to satisfy, and no tooling that produces evidence without leaking the evidence. Every published number comes from running this repository. The strict reading of “would the general public benefit” is weaker — the buyer is a regulated institution, not a consumer.

Local AI Implementation

A multilingual encoder runs locally in the retrieval path, PII detection runs locally with zero third-party dependencies, and no cloud AI API is installed or reachable. Measured rather than asserted: the ablation shows the published metrics are unchanged with the embedding model removed, because 241 chunks is small enough for lexical retrieval to cope. What genuinely disappears without local inference is the ability to do the work at all without disclosure.
