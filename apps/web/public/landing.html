Egress Guard

Paste anything a staff member might send to an external AI. Seventeen identifier types, from SSS and TIN through PhilSys ID, GCash numbers and cards, are found and redacted, then the detector is run again over Isla AI's own output. Anything that survives is escalated instead of sent.

DPA Copilot

Ask the Data Privacy Act in Taglish or English. Hybrid retrieval over 348 chunks from 11 verified instruments returns quoted spans with resolvable citations, and refuses outright when the evidence is thin. A wrong circular number is worse than no answer.

Fraud & AML Screen

Describe a transaction or account behaviour and get back a risk tier, who is exposed, the exact words that tripped each indicator, and the action required. Twenty typologies, from structuring to money-mule accounts to elder financial abuse.

recall 94.4% tier accuracy 100% 0 false positives on routine 4 ms p50

Audit Ledger

Every action writes a SHA-256 hash-chained record. Each entry links to the one before it, so altering a single entry invalidates everything after it and one pass detects it. Counts and verdicts only. The customer text is never written to disk.

verified in one pass no raw PII on disk cross-process safe

Built to survive a compliance officer.

The difference between a demo and a control you can be held to is whether someone else can check the work. Every claim below is verifiable.

The law is fetched, never written from memory

Each instrument is downloaded from its official source and stored with a fingerprint. Nothing is paraphrased or summarised by hand, so there is no copy of the law inside this product that can quietly drift away from the gazette.

Answers quote, they never generate

Every answer is a verbatim span from a retrieved section, with the section attached. When the evidence is thin it refuses. The worst outcome is an irrelevant paragraph, never an invented circular number.

It re-checks its own work

After redaction the detector runs again over the output, so a leak that slips past the first pass cannot reach the clipboard. That is why residual leakage measures zero rather than merely being low.

It tells you what it cannot verify

Where a governing rule is not in the corpus, the product says so on screen instead of implying coverage. A tool that is visibly incomplete is worth something in a regulated room. One that is confidently wrong is worth less than nothing.

Nothing leaves the premises

One machine, one process, no cloud AI service anywhere in the request path. The browser is forbidden by policy from fetching anything off-origin, so the pages cannot phone home even by accident.

Proof an examiner can read

Every action is written to a hash-chained ledger, so altering a single record invalidates everything after it. It records counts and verdicts, never the customer text, so the evidence is itself safe to keep.

What it is built on.

Named, open, and running on your own hardware. The inference stack is local, so the weights never leave the building either.

The project

Project name Isla AI — In-Situ Local AI
Short description An on-device compliance copilot for Philippine banks. It redacts customer data before a staff member pastes it into an external AI, screens transactions for fraud and money-laundering risk, and answers privacy and banking law with the exact section the answer came from. All of it runs on the bank's own hardware.
Team Boundless IT Solutions — Malcolm Joaquin Cuady (Developer), Mark Quiazon (Project Manager)
Repository github.com/jcuady/ISLA-AI
Hardware tested on AMD Ryzen 9 6900HS, 8 cores / 16 threads, 15.2 GB RAM, Windows 11. CPU only — no GPU and no dedicated accelerator.

What runs locally Everything. PII detection and redaction, the retrieval engine and its embedding model, fraud and AML screening, the audit ledger, the air-gap probe, both web surfaces, and the whole evaluation suite. No component needs a network call to function.
What requires internet Installation only. Model weights are fetched once and the legal corpus is downloaded from official sources on the first build. After that the product needs no network at all.

The disclosures

Models used multilingual-e5-small, int8 ONNX (MIT), for retrieval. Qwen2.5-3B Instruct Q4_K_M (Apache-2.0) and GLiNER multi-v2.1 (Apache-2.0) are optional, were not loaded, and produced none of the figures on this page.
Technologies Python 3.12, FastAPI, Uvicorn, Pydantic, ONNX Runtime, Transformers, PyTorch, rank-bm25, React 18, TypeScript, Vite, Tailwind CSS, Radix UI, pytest, Vitest, Playwright, GitHub Actions
APIs and cloud services None at runtime. No cloud AI provider is installed, called or reachable. No telemetry, no analytics, no error reporting. The only network use is fetching model weights during installation.
Existing code and assets Third-party model weights and the llama.cpp binary are pinned by version and downloaded rather than committed. Legal texts are unmodified public primary sources with their URLs and checksums recorded. Evaluation data is synthetic; no real customer records were used. Everything else, including the mark, was made for this product.
AI development tools Disclosed in full rather than implied: an AI coding assistant built the implementation end to end, AI image generation produced the mark and the hero photograph, and an AI diagram tool produced the architecture figure.
