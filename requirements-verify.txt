# Minimal dependency set to reproduce every published number and run the test
# suite. Deliberately excludes torch / transformers / onnxruntime.
#
# Why this file exists: the Egress Guard is pure Python standard library, and the
# copilot falls back to BM25 + section matching when no model weights are present.
# Both facts are asserted in CI, so a reviewer can clone this repo, run two pip
# installs, and independently regenerate eval/RESULTS.md without a GPU, without
# 2 GB of weights, and without a network connection.
#
#   pip install -r requirements-verify.txt
#   python -m pytest tests/ -q
#   python eval/run_eval.py
#
# fastapi / pydantic are here only because tests/test_audit_events.py exercises
# the /api/airgap endpoint, which is where the decision "record this probe in the
# ledger" is actually made. Every other module those tests reach - airgap.py,
# ledger.py, pii/engine.py, copilot/copilot.py - is standard library.
#
# This does NOT weaken the zero-dependency claim. The CI job that proves it
# (pii-guard) installs nothing at all and runs `eval/run_eval.py --pii-only`,
# which never imports the API layer. If a future edit ever pulls a real ML
# dependency into the Egress Guard hot path, that job fails.
